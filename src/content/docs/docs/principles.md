These are the rules every OASA project is built to. They spell out the "How we build" part of OASA's [core values](https://github.com/joinoasa/brand/blob/main/documents/core-values/core-values.md). For why OASA exists and where it's headed, read the [manifesto](https://github.com/joinoasa/brand/blob/main/documents/manifesto/manifesto.md).

## People first

- **Safety first.** Safety comes before speed, autonomy and everything else. Systems fail safe, keep the right people in control, and grow more careful as the stakes rise. When a machine isn't sure, it doesn't guess.
- **Piloted and autonomous.** Every system can be operated by a person and can run on its own.
- **Trained users.** Every system ships with a training course.
- **Affordable and accessible.** Anyone can take part without multimillion-dollar gear.
- **Contribution is rewarded.** Great members get recognition and a path into paid work.

## Secure, always

- **Encrypted, always.** Every link, radio, mesh, tether, cellular or acoustic, is encrypted. OASA never sets a standard that broadcasts information to the world.
- **Decentralized.** No single server, company or person is required for the system to work, and the people authorized to run it can always take control or shut it down.
- **Secure by design.** Security is built in from the first line of code.
- **Red team everything.** We try to break our own systems before anyone else does.

## Open by default

- **Open by default.** Designs, code and docs are published, with clear exceptions only where privacy, safety, security or the law require them.
- **Open-minded.** If others are doing great work, integrate it. If it doesn't exist, build it.
- **Interoperable.** Follow existing standards and publish OASA standards where gaps exist.
- **Reproducible.** Every project can be built by someone else from its documentation.

## Built to last

- **Sustainable and maintainable.** Repairable, documented, built to keep running for years.
- **Build at scale.** Every design is planned to be built in quantity, by any chapter.
- **Works at every scale.** One person with one device, a small team, or a fleet of hundreds.
- **Made in America, secure by default.** U.S.-built, encrypted systems, with designs and security reviews published so anyone can check them.

## One shared picture

- **Everything on TAK.** Every system appears on the same shared map that agencies already use. See the [glossary](/docs/glossary/) for TAK.
