You don't need to code to build robots, drones and boats with OASA. Plenty of the work is mechanical, electrical, testing, writing, design and organizing. This page is your path in.

## Work you can do

| If you're good at | You can |
|---|---|
| CAD, fabrication, 3D printing | Design and build parts for tech tree nodes; share models and print settings |
| Electronics, wiring, radio | Build and test harnesses, power systems and radios; document wiring |
| Testing and field work | Run test plans, record results, photos and video; report what broke |
| Writing and docs | Write guides, build logs and how-tos; improve these docs |
| Design and media | Diagrams, renders, photos, video, brand material |
| Organizing and outreach | Events, build days, chapters, partners, recruiting |

## The tools you'll use

- **GitHub, in your browser only.** You read and comment on issues, and claim work there. You never need to install Git. To fix a doc, click **Edit page** at the bottom of any docs page and GitHub walks you through it.
- **The shared drive** ([share.joinoasa.org](https://share.joinoasa.org)) for CAD, data, photos and video.
- **Discord** for questions, voice calls and build days.
- **Your OASA email** for anything outside OASA.

## Your first week

1. Finish the [setup checklist](/docs/setup-checklist/) with your buddy. Skip the code-only steps.
2. Browse the [tech tree](/techtree/) and pick one or two nodes that match your skills. Each node lists what it needs.
3. Ask your buddy for a first task, or comment on a node's issue saying what you could help with.
4. Follow [How work gets done](/docs/how-work-gets-done/). Your files go in the drive under `Projects/<node ID> <name>/`, and your updates go on the issue.

## Good first tasks

- Test a build guide and fix what's unclear.
- Photograph and document a part or assembly.
- Turn a Discord discussion into a short doc.
- Model a simple bracket or enclosure a node needs.

## Using AI without code

AI is welcome for non-code work too: drafting docs, checking a test plan, explaining a datasheet, brainstorming. Try the [AI brainstorming guide](/docs/brainstorm/). Check what it tells you before you share it.
