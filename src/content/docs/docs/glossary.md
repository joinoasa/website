---
title: Glossary
description: Plain definitions of the terms used across OASA docs and the tech tree.
lastUpdated: 2026-10-20
---

**ArduPilot.** Open source autopilot software for aircraft, vehicles and boats.

**ArduSub.** The ArduPilot variant for underwater vehicles.

**ATAK-CIV.** The civilian version of the Android Team Awareness Kit map app.

**beamforming.** Steering a radio beam toward a receiver with an antenna array, instead of broadcasting in all directions.

**BOM.** Bill of materials: the list of parts needed to build something.

**CoT (Cursor-on-Target).** The message format TAK uses to share positions and status.

**DroneCAN.** A wired messaging protocol for connecting parts inside a drone.

**fiscal sponsor.** An established nonprofit that holds funds and handles legal matters for a project until it can stand alone.

**FreeTAKServer.** An open source server for TAK.

**GCS (ground control station).** The computer or controller used to monitor and command a drone.

**GNSS.** Satellite navigation, such as GPS.

**LoRa.** A long-range, low-power radio technology.

**MAVLink.** An open messaging protocol between drones and ground stations.

**MAVSDK.** A software library for controlling MAVLink vehicles from code.

**mesh.** A network where each device relays traffic for the others, so data takes the best available path.

**Meshtastic.** An open source mesh messaging project built on LoRa radios.

**node (tech tree).** One capability on the [tech tree](/techtree/) that members can build, and that other nodes depend on.

**PX4.** Open source autopilot software for drones.

**relay drone.** A drone that carries a radio to extend range for others.

**Remote ID (ASTM F3411).** A standard for drones to broadcast identification during flight, as FAA rules require.

**ROS 2.** An open source framework for building robot software.

**ROV.** Remotely operated vehicle, usually underwater.

**RTK.** A GNSS correction method that gives centimeter-level positions.

**SDR.** Software-defined radio: a radio whose behavior is set in software.

**SITL.** Software-in-the-loop: running vehicle software in a simulator.

**TAK (Team Awareness Kit).** A shared map used by agencies and teams. OASA systems are designed to appear on it.

**VTOL.** Vertical takeoff and landing aircraft.
